# Khalil Dridi | Personal Portfolio

Professional portfolio web application designed to showcase my
professional profile, technical skills, academic background,
projects and achievements.

## Project Vision

Build a modern, responsive, interactive and fully manageable
portfolio accessible publicly through a custom domain.

## Planned Technology Stack

### Frontend
- Angular
- TypeScript
- SCSS
- Three.js
- GSAP

### Backend
- Java 21
- Spring Boot
- REST API
- Spring Security
- JWT

### Database
- MySQL

### Infrastructure & Deployment
- Git & GitHub
- Docker
- Nginx
- Azure (subject to available credits)

## Project Structure

- `frontend/` - Angular application
- `backend/` - Spring Boot application
- `infra/` - Infrastructure and deployment configuration
- `docs/` - Project documentation
- `.github/` - GitHub workflows
